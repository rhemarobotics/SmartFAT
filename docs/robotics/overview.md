實習目的

- 掌握正逆運動學基礎與應用：學習如何計算機器人的正運動學（末端位置）與逆運動學（關節角度），並應用於機器人的路徑規劃。
- 理解感測器數據處理與應用：熟悉馬達內部感測器（如編碼器、溫度感測器）的數據讀取與分析，了解如何通過感測器反饋優化運動控制。
- 實現精確運動控制：學習如何實現機器人的軌跡規劃、速度與加速度控制，確保機器人能在不同的負載和環境下穩定運作。
- 解決實際應用場景問題：設計並實現機器人的自動化任務，如抓取、裝配和移動，提升實際操作技能。

# **產業機器人簡介**

產業機器人是自動化技術的核心設備，能通過程式設計和控制，完成重複性或精確性的工業操作。它們通常由機械結構、感測器、控制系統和驅動裝置組成，適用於多種生產場景，如焊接、組裝、搬運等。

## 一、機器人四大家族

產業機器人領域有四大主要製造商，被稱為「四大家族」，它們主導著全球市場：

1. **ABB**
    - 瑞士/瑞典跨國公司，以多軸機器人聞名，專注於靈活性和節能設計。
    - 產品涵蓋焊接、包裝、塗裝等應用。
2. **KUKA（庫卡）**
    - 德國品牌，專注於智能工廠和工業 4.0，擁有高負載機器人的領先技術。
    - 在汽車製造和重工業應用廣泛。
3. **Fanuc（發那科）**
    - 日本品牌，專注於高精度和穩定性，特別是在 CNC 系統和機器人控制領域。
    - 主要應用於汽車、電子和金屬加工行業。
4. **Yaskawa（安川電機）**
    - 日本品牌，以伺服馬達技術起家，擅長高速和精確的機器人解決方案。
    - 主要應用於食品加工、醫療設備和電子行業。

## 二、機器人基本分類

根據結構和應用，產業機器人可分為以下幾種類型：

**按結構分類**：

- **直角坐標機器人**：運動軌跡為線性，適合高精度搬運和裝配。
- **平行機器人（Delta Robot）**：高速輕負載運動，適合食品和電子行業。
- **SCARA 機器人**：具有快速重複性運動，適用於電子組裝、點膠等。
- **六軸機器人**：靈活性最高，可進行多方向操作，適合焊接、噴塗和裝配。
