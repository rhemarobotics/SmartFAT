# 8. 機器視覺實務技術

Owner: 耿良 王
Tags: tutorial documents
Date: March 1, 2024

<aside>
💡

隨著工業 4.0 和智慧製造的發展，機器視覺與運動控制系統的整合成為重要技術。它可代替人眼進行非接觸式測量和判斷，提升加工精度，檢測產品缺陷，並提高自動化生產效率。同時，機器視覺結合機器手臂，能強化機器人對設備的整合能力，滿足高靈活性製造需求。

未來，機器視覺將助力機器人實現智慧學習與自主控制。例如，操作員只需示範一次正確操作，機器人即可透過機器視覺快速學習並執行任務，進一步適應開放、變動和非結構化的工作環境。

</aside>

- 學習使用 OpenCV 進行基礎影像處理
