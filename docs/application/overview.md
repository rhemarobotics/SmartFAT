# 6. 物聯網應用層

Owner: 耿良 王
Tags: tutorial documents
Date: March 1, 2024

<aside>
💡 物聯網（IoT）應用層是整個物聯網架構中與使用者最密切相關的一層，它負責將底層感知層收集的數據進行處理、分析並轉化為具體應用，滿足不同領域的需求。應用層技術涉及到數據分析、可視化和智能決策等關鍵環節，能夠支援多種終端應用，如智慧城市、智慧家居、工業自動化、醫療健康等。

</aside>

應用層的核心技術包括：

- 數據處理與分析：收集並分析大量來自感知層的數據，通過雲端運算和大數據技術，為用戶提供即時且精準的決策支援。
- 數據可視化：將複雜的數據以簡明易懂的圖形化界面展示，便於用戶監控設備狀態或環境變化。
- 智能決策系統：利用人工智慧（AI）技術，應用層能實現自動控制和智能化決策，提高應用系統的自適應能力。
應用層技術的發展不僅提升了物聯網系統的效能，還促進了跨行業應用的深入發展，將數據轉化為更具價值的實際行動。

# **IOT視覺化開發工具(Node-RED)**

## 一、Node-RED簡介

- Node-RED是IBM推出的一款**基於流程編程的視覺化程式開發工具**，主要用於物聯網(IoT)相關程式的開發並於2016年成為開源JS基金會的子項目。Node-RED係以Node.js為基礎，發展出來的視覺化程式開發工具，就算完全不會 Node.js，也可以透過視覺化的功能模組，以流程編程的方式，達到程式開發的目的。

## 三、Node-RED 基本操作

Node-RED 是一個基於流程的開源開發工具，特別適合處理物聯網（IoT）應用。使用它可以輕鬆地將不同的設備、API 和服務整合在一起。以下是 Node-RED 的基本操作介紹。

1. Node-RED 編輯器的基本組件
    - 工作區（Workspace）：拖放節點和建立流程的主要區域。
    - 節點面板（Nodes Panel）：在左側顯示各種節點（如輸入、輸出、函數等），可以將這些節點拖放到工作區中。
    - 屬性面板（Properties Panel）：在右側，選中節點後可以在此編輯其屬性（如名稱、參數）。
    
    ![image.png](../assets/6%20%E7%89%A9%E8%81%AF%E7%B6%B2%E6%87%89%E7%94%A8%E5%B1%A4/image%201.png)
    
2. 建立流程（Flow）
    - 拖動節點：從左側的節點面板中拖動節點（如 Inject 節點、Debug 節點）到工作區。
    - 連接節點：點擊節點的輸出端口（右側小圓點），拖動至另一個節點的輸入端口（左側小圓點），即可建立連接。
    - 設置節點屬性：點擊節點打開屬性面板，進行設置。例如，可以在 Inject 節點中設置觸發時間，在 Debug 節點中設置輸出格式。
        
        ![2024-03-14-092337_586x135_scrot.png](../assets/6%20%E7%89%A9%E8%81%AF%E7%B6%B2%E6%87%89%E7%94%A8%E5%B1%A4/2024-03-14-092337_586x135_scrot.png)
        
3. 部署流程
    - 配置流程完成後，點擊右上角的「Deploy」按鈕以部署並啟動流程。
    - 部署後，流程將自動開始運行，並按照設置執行。
        
        ![2024-03-14-092354_187x66_scrot.png](../assets/6%20%E7%89%A9%E8%81%AF%E7%B6%B2%E6%87%89%E7%94%A8%E5%B1%A4/2024-03-14-092354_187x66_scrot.png)
        
4. 查看日誌（Debug）輸出
    - 使用 Debug 節點來查看流程中的數據。將 Debug 節點連接到想要監控的節點上，並設定 Debug 節點的輸出。
    - 點擊「Debug」窗口（右側）即可查看數據流和運行結果，便於調試和測試。
5. 保存和導出/導入流
    - 保存流程：Node-RED 會自動保存已部署的流程。
    - 導出流程：點擊右上角菜單，選擇「Export」，可以將流程以 JSON 格式複製或下載，用於備份或分享。
    - 導入流程：選擇「Import」，將 JSON 格式的流程粘貼進去或上傳文件，即可導入流程。
        
        ![2024-03-14-092548_237x489_scrot.png](../assets/6%20%E7%89%A9%E8%81%AF%E7%B6%B2%E6%87%89%E7%94%A8%E5%B1%A4/0b64be65-c85a-40b6-8bec-595c7fd1dc8e.png)
        
    
    ![2024-03-14-092624_625x530_scrot.png](../assets/6%20%E7%89%A9%E8%81%AF%E7%B6%B2%E6%87%89%E7%94%A8%E5%B1%A4/2024-03-14-092624_625x530_scrot.png)
    
    ![2024-03-14-092650_623x527_scrot.png](../assets/6%20%E7%89%A9%E8%81%AF%E7%B6%B2%E6%87%89%E7%94%A8%E5%B1%A4/2024-03-14-092650_623x527_scrot.png)
    
6. 常用節點
    - Inject：用於手動觸發消息或設置定時觸發。
    - Debug：顯示輸出消息，方便調試流程。
    - Function：編寫自定義 JavaScript 代碼來處理數據。
    - Template：將數據格式化輸出，通常用於生成 HTML 或文本格式。
        
        ![2024-03-14-092502_723x142_scrot.png](../assets/6%20%E7%89%A9%E8%81%AF%E7%B6%B2%E6%87%89%E7%94%A8%E5%B1%A4/2024-03-14-092502_723x142_scrot.png)
        
7. 總結
    - Node-RED 的操作簡單易用，只需拖放節點並連接它們即可設計流程。通過「Deploy」部署後，即可運行和調試。Node-RED 提供了豐富的節點和插件，非常適合快速構建 IoT 和數據處理應用。
