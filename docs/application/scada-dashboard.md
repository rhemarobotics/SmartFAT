# **壹**、**SCADA監控系統概述**

SCADA（Supervisory Control and Data Acquisition）監控系統是一種用於監控和控制工業過程的電腦系統。它具有以下基本功能和架構：

1. **監控（Supervisory）**：
    - 監控是SCADA系統的主要功能之一，它通過監測和收集實時數據來實現對工業過程的實時監控。
    - SCADA系統可以連接到各種感測器、儀表和控制設備，並實時顯示相關數據，如溫度、壓力、流量等。
2. **控制（Control）**：
    - 控制是SCADA系統的另一個重要功能，它可以通過遠程控制設備來調節和控制工業過程。
    - SCADA系統可以向遠端設備發送命令，例如打開或關閉閥門、調節馬達速度等，以實現對工業過程的精確控制。
3. **數據收集和存儲**：
    - SCADA系統能夠自動收集並存儲大量的數據，包括實時數據、歷史數據和事件數據。
    - 這些數據可以用於後續分析、報告和決策，有助於優化生產過程和提高生產效率。
4. **人機界面（Human-Machine Interface，HMI）**：
    - HMI是SCADA系統的用戶界面，它通常由圖形化的操作界面和控制面板組成。
    - 通過HMI，用戶可以實時監控工業過程的狀態，並通過操作界面來執行相關的控制和操作。
5. **報警和事件管理**：
    - SCADA系統能夠監測過程中的異常狀態，並及時發出警報。
    - 同時，它還能夠記錄和管理事件，包括故障報警、操作記錄等，以便後續分析和處理。

總結，SCADA監控系統的基本功能是實時監控工業過程、實現對遠端設備的控制、收集和存儲數據、提供用戶友好的人機界面以及管理報警和事件。這些功能使得SCADA系統成為工業自動化和生產管理中不可或缺的重要工具。

# 貳、**Node-RED中的SVG圖形和動畫**

<aside>
💡 介紹如何使用Node-RED的SVG節點創建和編輯圖形及演示如何在SVG圖形上添加動畫效果，以增強監控系統的視覺吸引力。

</aside>

要使用 Node-RED 的 SVG 節點創建和編輯圖形，可以按照以下步驟進行：

1. **新增 SVG 節點**：
    - 打開 Node-RED 編輯器並創建一個新的流程。
    - 從左側的「輸入」欄中找到 **SVG 節點**，然後將其拖放到工作區。
        
        ![image.png](../assets/6%20%E7%89%A9%E8%81%AF%E7%B6%B2%E6%87%89%E7%94%A8%E5%B1%A4/6%205%20%E6%89%93%E9%80%A0%20SCADA%20%E7%9B%A3%E6%8E%A7%E7%B3%BB%E7%B5%B1%E5%84%80%E8%A1%A8%E6%9D%BF/image.png)
        
        <aside>
        🔗 需要先安裝 **node-red-contrib-ui-svg** 節點，它可以從“面板管理”選項安裝，也可以通過以下方式手動安裝：
        
        ```bash
        npm install node-red-contrib-ui-svg
        ```
        
        </aside>
        
2. **設置 SVG 節點**：
    - 雙擊 SVG 節點以設置其屬性。
    - 在節點配置窗口中，您可以選擇創建新的 SVG 圖形，或者導入現有的 SVG 檔案。
        - 如果選擇創建新的 SVG 圖形，您可以指定圖形的尺寸、填充顏色、邊框顏色等屬性。
        
        ![image.png](../assets/6%20%E7%89%A9%E8%81%AF%E7%B6%B2%E6%87%89%E7%94%A8%E5%B1%A4/6%205%20%E6%89%93%E9%80%A0%20SCADA%20%E7%9B%A3%E6%8E%A7%E7%B3%BB%E7%B5%B1%E5%84%80%E8%A1%A8%E6%9D%BF/image%201.png)
        
3. **編輯 SVG 圖形**：
    - 在 SVG 編輯器中，您可以使用繪圖工具（如矩形、圓形、直線等）創建圖形，也可以直接編輯 SVG 代碼，可以調整圖形的大小、位置、填充和邊框等屬性，並添加動畫效果。
        
        ![image.png](../assets/6%20%E7%89%A9%E8%81%AF%E7%B6%B2%E6%87%89%E7%94%A8%E5%B1%A4/6%205%20%E6%89%93%E9%80%A0%20SCADA%20%E7%9B%A3%E6%8E%A7%E7%B3%BB%E7%B5%B1%E5%84%80%E8%A1%A8%E6%9D%BF/image%202.png)
        
        ![image.png](../assets/6%20%E7%89%A9%E8%81%AF%E7%B6%B2%E6%87%89%E7%94%A8%E5%B1%A4/6%205%20%E6%89%93%E9%80%A0%20SCADA%20%E7%9B%A3%E6%8E%A7%E7%B3%BB%E7%B5%B1%E5%84%80%E8%A1%A8%E6%9D%BF/image%203.png)
        
4. **保存和部署**：
    - 當您完成對 SVG 圖形的編輯後，點擊「完成」按鈕以保存更改。
    - 確保保存了您的流程，然後點擊「部署」按鈕以使更改生效。
5. **查看效果**：
    - 打開 Node-RED 中的預覽頁面，或者在瀏覽器中訪問 Node-RED 的 HTTP 地址以查看您創建的 SVG 圖形。
    - 您還可以在其他節點中使用 SVG 圖形，例如在 Dashboard 節點中創建儀表板。

通過以上步驟，您可以使用 Node-RED 的 SVG 節點輕鬆創建和編輯 SVG 圖形，為您的項目增添更多的視覺效果和互動性。

<aside>
💡

- 詳細步驟可以利用 Node-Red [網站資源](https://flows.nodered.org/)🌍，獲取有關 SVG 動畫的更多資訊，包括動畫相關的設定和資源等。
</aside>

<aside>
💡 在智慧工廠的時代，SCADA（監控和數據採集系統）成為不可或缺的核心技術。設計一個SCADA監控系統，不僅是提升生產效率的關鍵，更是確保設備運行穩定與安全的保障。透過即時監控、數據分析和遠程控制，SCADA系統可以幫助企業實現自動化管理，減少人工干預和操作失誤。現在，我們將展開這項設計工作，為未來工廠建立一個強大而靈活的監控平台，提升競爭力，邁向智慧製造的未來。。

</aside>
