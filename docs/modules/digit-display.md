# **貳、數字顯示器**

<aside>
💡

數字顯示器（Numeric Display）廣泛應用於各種需要顯示數字資訊的場景。其主要用途如下：電子時鐘和手錶、測量儀器：如電壓表、溫度計、秤重器等，顯示測量數值。工業設備顯示：顯示工業控制系統中的參數，如速度、壓力、流量等。數字顯示器以其直觀簡單、易於閱讀的特性，適合在各種需要數值反饋的應用中使用。

- 感測器原理
    
    TM1650 是一種常用的 LED 驅動控制芯片，專門用來驅動 7 段數字顯示器 或 點陣顯示器。該芯片可以控制多個數字顯示器和 LED 燈，且通過簡單的 I²C 或 I2C 通信方式與主控板連接，常用於電子鐘、計數器等數字顯示設備。

## 四、範例程式

```arduino
/*****************************************************
 * SegDisplay.ino 
 * 目的:
 *  測試數字顯示器功能
 * 方法:
 *  數字顯示器
 * 步驟:
 *  直接執行程式
 * 結果:
 *  觀察數字顯示器是否顯示"1234",間隔2秒後,然後畫面清空
*****************************************************/

#include <Wire.h>
#include <TM1650.h> //掛載數字顯示器標頭檔

TM1650 disp;        //宣告數字顯示器物件

/************************* 初始設定 *********************/
void setup() 
{
  Wire.begin();
  disp.init();      //初始化數字顯示器物件
}

/************************* 主程式 ***********************/
void loop() 
{
  
  char line[] = "1234"; 
  disp.displayString(line);                      //設定數字1234
  disp.setBrightnessGradually(TM1650_MAX_BRIGHT);//設定最大亮度顯示
  disp.displayOn();                              //顯示數字1234  
  delay(2000);                                   //延遲2秒
  
  disp.setBrightnessGradually(TM1650_MIN_BRIGHT);//設定最小亮度顯示
  disp.displayOff();                             //清除畫面 
  delay(2000);                                   //延遲2秒 
}
```

## 四、實習結果

- 觀察數字顯示器是否顯示"1234",間隔2秒後,然後畫面清空。
