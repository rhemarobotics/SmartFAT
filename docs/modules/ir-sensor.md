# **貳、紅外線感測器**

<aside>
💡

紅外線感測器（Infrared Sensor）是一種能夠檢測**紅外線（波長在700nm至1mm之間）**的電子元件，主要用於偵測物體發出的紅外輻射或反射的紅外光。紅外線感測器用途廣泛，特別適合於無需可見光的應用場景。

- 非接觸測量：無需接觸物體即可感知溫度、距離或存在，適合無菌環境和危險區域使用。
- 抗干擾能力強：不受可見光干擾，適合在各種光線條件下使用。

## 一、實習目的

- 了解紅外線感測器的原理和電路接線圖
- 透過Arduino程式，讀取並分析感測器數據

## 二、實習設備與材料

- 紅外線感測器
    
    ![image.png](../assets/4%20%E7%89%A9%E8%81%AF%E7%B6%B2%E7%B0%A1%E4%BB%8B/4%205%20%E7%B4%85%E5%A4%96%E7%B7%9A%E6%84%9F%E6%B8%AC%E5%99%A8%E5%AF%A6%E7%BF%92/image%201.png)
    
- 感測器原理
    
    感測器具有一個紅外線發射管和一個紅外線接收管，當發射管的紅外信號經反射被接收管接收後，接收管的電阻會發生變化，透過類比電壓的輸出表現出來。電阻的變化取決於反射面的顏色和反射面接收管的距離兩方面。

## 四、範例程式

```arduino
/*****************************************************
 * IRDetectSensor.ino 
 * 目的:
 *  測試紅外線感測器功能
 * 方法:
 *  紅外線感測器(調整感測器上的可變電阻，可改變偵測距離)
 * 步驟:
 *  把物體放置於紅外線感測器前, 動態調整距離
 * 結果:
 * 1. 當感測器偵測到物體,觀察感測器上的LED是否亮起
 * 2. 觀察序列埠監看視窗,當偵測到物件時,顯示"Object Detected"
******************************************************/

#define IR_PIN 40  //定義紅外線感測器腳位連接至40腳
uint8_t IR_value;  //紅外線感測器數位狀態

/************************* 初始設定 *******************/
void setup()
{
  Serial.begin(9600);
  pinMode(IR_PIN, INPUT); //設定IR_PIN為輸入接腳
}

/************************* 主程式 *********************/
void loop()
{
  IR_value= digitalRead(IR_PIN); //讀取紅外線感測器數位狀態(0或1)
  Serial.println(IR_value);      //序列埠輸出數位狀態
    
  if (IR_value == 1)        
  {
    Serial.println("Nothing.");        //沒有偵測到物件
  }
  else
  {
    Serial.println("Object Detected.");//有偵測到物件
  }
  
  delay(1000);
}

```

## 四、實習結果

- 當感測器偵測到物體，觀察感測器上的LED是否亮起。
- 觀察序列埠監看視窗，當偵測到物件時，顯示 "Object Detected"。
