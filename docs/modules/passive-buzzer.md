# **貳、無源蜂鳴器**

<aside>
💡

電子專案中常用的壓電蜂鳴器有兩種類型——有源蜂鳴器和無源蜂鳴器。有源蜂鳴器之所以稱為有源蜂鳴器，是因為它們只需要直流電壓即可產生聲音。無源蜂鳴器需要交流電壓來產生聲音。

與有源蜂鳴器相比，無源蜂鳴器的一個優點是您可以控制蜂鳴器產生的聲音的音調或音高。對於有源蜂鳴器，只能使用一種音調，而對於無源蜂鳴器，可以在蜂鳴器的動態範圍內使用任何音調。

## 二、實習設備與材料

- 無源蜂鳴器
    
    ![image.png](../assets/4%20%E7%89%A9%E8%81%AF%E7%B6%B2%E7%B0%A1%E4%BB%8B/4%2010%20%E7%84%A1%E6%BA%90%E8%9C%82%E9%B3%B4%E5%99%A8%E5%AF%A6%E7%BF%92/image%201.png)
    
- 感測器原理
    
    有源和無源蜂鳴器是磁性蜂鳴器的類型。在蜂鳴器內部，有一個連接到蜂鳴器引腳的線圈。還有一個圍繞線圈的圓形磁鐵。頂部附有金屬重物的薄金屬膜位於圓形磁鐵和線圈線圈的上方。當電流脈衝施加到線圈上時，磁感應會導致金屬重量和金屬膜上下振動。金屬膜的振動產生聲波。

## 四、範例程式

```arduino
/*****************************************************
 * Buzzer.ino 
 * 目的:
 *  測試蜂鳴器功能
 * 方法:
 *  蜂鳴器
 * 步驟:
 *  直接執行程式
 * 結果:
 *  觀察蜂鳴器是否發出高低音頻的聲音
*****************************************************/

#define BUZZER_PIN 36 //定義蜂鳴器輸出腳位連接至36腳

/************************* 初始設定 *********************/
void setup()  
{  
    pinMode(BUZZER_PIN, OUTPUT); //設定BUZZER_PIN為輸出接腳
}  

/************************* 主程式 ***********************/
void loop()  
{  
    //設定音頻從低到高, 200Hz ~ 800Hz 
    for(int i = 200; i <= 800; i++)    
    {  
        tone(BUZZER_PIN, i);
    }  

    // 延遲1s
    delay(1000);                       

    //設定音頻從高到低, 800Hz ~ 200Hz
    for(int i= 800; i >= 200; i--)   
    {  
        tone(BUZZER_PIN, i);  
        delay(10);  
    }  
}
```

## 四、實習結果

- 觀察蜂鳴器是否發出高低音頻的聲音。
