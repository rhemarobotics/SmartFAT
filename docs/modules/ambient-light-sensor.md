# **貳、環境光感測器**

<aside>
💡

環境光感測器（Ambient Light Sensor）是一種能檢測周圍環境中的光強度的電子元件。主要是用於測量**環境照度(Lux)**，典型應用包括氣象站、太陽能農場、溫室和自動化設備，可以根據環境光線的變化來調整顯示設備的亮度或其他參數。環境光感測器因其靈敏度和低功耗，已經成為許多智慧設備和自動化系統中的關鍵元件。

## 二、實習設備與材料

- 環境光感測器
    
    ![image.png](../assets/4%20%E7%89%A9%E8%81%AF%E7%B6%B2%E7%B0%A1%E4%BB%8B/4%204%20%E7%92%B0%E5%A2%83%E5%85%89%E6%84%9F%E6%B8%AC%E5%99%A8%E5%AF%A6%E7%BF%92/image%201.png)
    
- 感測器原理
    
    光敏電阻（LDR，Light Dependent Resistor），又稱光電導體，是一種對光敏感的元件。其工作原理是基於光強度的變化來調節電阻值。當光照強度增強時，光敏電阻的電阻值會下降；當光照減弱時，電阻值會上升。這個特性使它能夠用來檢測光線的變化。

## 四、範例程式

```arduino
/*****************************************************
 * LightSensor.ino 
 * 目的:
 *  測試光敏感測器功能
 * 方法:
 *  光敏感測器
 * 步驟:
 *  遮蔽或無遮蔽光敏感測器,觀察輸出值變化
 * 結果:
 *  當光線變暗,數值則變小, 反之光線變亮,數值則變大
*****************************************************/

#define LIGHT_PIN A2  //定義光敏感測器腳位連接至A2腳

/************************* 初始設定 *******************/
void setup() 
{
  Serial.begin(9600);
}

/************************* 主程式 *********************/
void loop() 
{
  int lightValue = analogRead(LIGHT_PIN); //讀取光敏感測器值,0~1023
  Serial.println(lightValue);             //序列埠視窗輸出
  delay(100);
}
```

## 四、實習結果

- 遮蔽或無遮蔽光敏感測器，觀察序列埠輸出值變化。
