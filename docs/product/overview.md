Owner: 耿良 王
Tags: tutorial documents
Date: March 1, 2024

<aside>
🥇 **智慧工廠教學實驗平台**是雷瑪機器人基於智慧工廠理論與實務，精心設計和製造的教學實驗平台，旨在為課堂學習帶來更多的樂趣和啟發，同時提供一個互動式、實踐性強的學習體驗。實驗平台包含了一系列常用的感測器元件和客製的硬體設備，涵蓋了智慧工廠領域的各個方面，包含感測器、機器人、微電腦控制器到大數據分析和雲端連接等技術層面。針對工業4.0發展潮流，建立【智慧工廠】特色課程，深入淺出「工業4.0」、「智慧製造」與「智慧工廠」核心概念。

</aside>

# **壹、產品概述**

- 智慧工廠教學實驗平台**，**包含工廠常用感測器元件、Arduino 單晶片控制器、Raspberry Pi 微電腦控制器、智慧型機器人、機器視覺感測器、語音辨識及語音播報模組，如圖所示。透過完整的系統整合，使用者不用花費時間在複雜的電路板接線上，可以專注於智慧工廠各項關鍵技術的學習與應用。

## 智慧機器人

- 本平台使用的智慧機器人是一**六軸關節型機械人**，因其自由度高，工作空間大，目前是工業領域中最常見的工業機器人的形態之一。

# **叁、場域模擬**

- 透過智慧工廠教學實驗平台的虛實整合系統，模擬智慧工廠類產線情境場域，例如 :
    - 智慧工廠堆棧系統
    - 智慧工廠重量分檢系統
    - 智慧工廠雲端大數據可視化
    - 智慧工廠遠端控制系統
- 讓同學可以身歷其境(以安全的方式)體驗並了解智慧工廠的運作方式，增加同學的學習動機與興趣，幫助同學能深入地了解這些技術的內涵與應用方式。除此之外，還可以幫助老師們更容易地評估學生的學習成效，進而調整教學策略，提高學習成果。
