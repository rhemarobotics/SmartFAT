    8.1. 機器視覺簡介

    Owner: 耿良 王 Tags: tutorial documents Date: March 1, 2024

    什麼是機器視覺?

    機器視覺（Machine Vision） 是一種讓機器模仿人類眼睛看東西的技術。它利用攝影機拍攝影像，再透過電腦分析影像內容，判斷物體的狀態，並做出相應的動作或決策。

    機器視覺的運作方式是先使用攝影機與光學設備，在不接觸物體的情況下取得影像。接著，系統會分析影像中的亮度、顏色和形狀等資訊，從中找出需要的特徵，例如位置、大小或是否有缺陷，並依據分析結果進行判斷與控制。

    隨著工業 4.0 與智慧製造成為產業發展的重要方向，機器視覺常與自動化設備及運動控制系統結合，廣泛應用於現代工廠中。透過機器視覺，可以取代人工目視檢查，提高產品品質、降低錯誤率，並提升生產效率。

    當機器視覺搭配機器人或機械手臂使用時，機器能更準確地辨識周圍環境，完成取放、組裝或檢測等工作，適合需要高度彈性與自動化的生產環境。

    未來的機器人技術將朝向智慧學習與自主控制發展。只要人員示範正確的操作方式，機器人就能透過機器視覺學習並模仿，進而在較複雜、變動的環境中完成工作。

    相機基本原理與影像擷取

    📸 本單元介紹相機在機器視覺系統中的基本構成與運作原理，說明影像如何透過鏡頭與感測元件進行擷取，並轉換為數位影像資料。同時介紹常見相機類型與影像參數，讓學生了解影像品質與系統應用之間的關係，作為後續影像處理與辨識實作的基礎。

    一、相機基本光學參數

    掌握相機在機器視覺中的角色與功能，了解影像擷取原理及常見感測元件（CCD、CMOS）、影像基本參數（解析度、幀率、曝光），並能正確操作相機進行影像擷取以應用於後續影像處理：

    1. 解析度(Resolution)
      • 解析度指的是鏡頭能量測物體細節的能力，解析度越高的鏡頭成像越清晰。
    2. 工作距離(Working distance, WD)
      • 一般指的是鏡頭最前端到被測物之距離。

    3. 景深(Deep of Field, DOF)

      • 景深是指在被攝物體聚焦清楚後，在物體前後一定距離內，其影像仍然清晰的範圍。

    4. 可視範圍(Field of view, FOV)

      • 相機實際成像所看到的區域的大小。

    5. 焦距(Focal Length)

      • 從透鏡中心到光聚集之焦點的距離，量測單位為mm。短焦距提供廣角視野/長焦距提供望遠視野。

    6. CCD vs CMOS

      • CCD（Charge-Coupled Device）和 CMOS（Complementary Metal-Oxide-Semiconductor）是兩種常見的影像感測元件，它們在原理、特性和應用上有一些差異：

    7. 掃描方式 - 線型掃描以及面型掃描 

      • 掃描方式決定感測器如何讀取影像數據，主要有兩種：線型掃描（Line Scan）與面型掃描（Area Scan）

    二、相機解析度需求計算示例

    1. 遵循兩個主要步驟，選擇相機的解析度 (Resolution) 及焦距 (f)：

      • 計算感測最小解析度：欲辨識物件的FOV(field of view)及最小特徵值

      • 相機選擇：透過感測元件的尺寸，反推得到正確的相機焦距

    2. 步驟一： FOV為 500mm X 600mm，檢測精度要求 2mm，求最佳相機解析度?

      • 水平解析度 ≥ 300 pixels；垂直解析度 ≥ 250 pixels

    3. 步驟二： 已知相機像素大小 3.75 x 3.75um 及解析度 1280 x 1024 pixels，求相機焦距?

      • (3.75umx1280) x (3.75umx1024) = 4.80 x 3.84mm = 1/3”

    三、相機規格

    本課程選用的相機規格，有些規格參數會直接影響影像品質與應用效果，需要特別注意，主要包括：

    1. 解析度（Resolution）
      • 決定影像細節能力，像素越多可分辨的細節越細。
      • 注意感測器尺寸和像素大小也會影響畫質。
    2. 幀率 / 影格速率（Frame Rate / FPS）
      • 每秒能擷取的影像數量，高速動態場景需高幀率。
    3. 感測器類型（CCD / CMOS）
      • 影像品質、功耗與讀取速度不同，依應用選擇。
    4. 曝光時間（Exposure Time / Shutter）
      • 影響影像亮度與動態模糊，動態場景需短曝光。
    5. 光學參數
      • 焦距（Focal Length）：影響視場大小與放大倍率。
      • 工作距離（Working Distance）：相機到物體的距離。
      • 景深（Depth of Field）：清晰成像的距離範圍。
      • 視場 / 可視範圍（Field of View）：相機可捕捉的範圍大小。
    6. 靈敏度 / 信噪比（Sensitivity / SNR）
      • 在低光環境下影像的清晰度與噪聲程度。
    7. 接口 / 傳輸方式（USB, GigE, Camera Link…）
      • 影像傳輸速率與穩定性，決定能否符合應用需求。
